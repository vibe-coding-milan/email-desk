# Companion artwork history

The composite stills below are retained design assets. The current interface composes the drawn idle sprite with stationary props; see [COMPANION-IDLE.md](COMPANION-IDLE.md). Whole-image nod/pulse effects were superseded before publication.
Milan approved the consistent cobalt/cream robot in the three-scene concept and requested lightweight motion. Selected transparent derivatives were generated with built-in ImageGen and saved in public/assets. CSS supplies brief nod/light pulses; no GIF/video or animation dependency is needed. Original generated files are preserved outside the workspace. Existing prop-only artwork is retained for history.
